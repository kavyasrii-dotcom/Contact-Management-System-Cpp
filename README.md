Contact Management System

A simple console-based Contact Management System developed using C++.

Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Delete contacts by name
- Store contact details using file handling

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

Concepts Demonstrated

- Classes and objects
- Functions
- String manipulation
- File input and output
- CRUD operations

How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE or terminal.
3. Compile the source code:

g++ ContactManagement.cpp -o ContactManagement

4. Run the program:

./ContactManagement

On Windows, run:

ContactManagement.exe

Data Storage

Contact details are stored locally in "contacts.txt", which is automatically created when a contact is added.

Author

Developed as a beginner-level C++ project to practice programming fundamentals and file handling.
